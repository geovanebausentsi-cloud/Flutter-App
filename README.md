# Datatable no Flutter
 No Flutter, o DataTable é um widget utilizado para exibir informações de forma 
organizada em formato de tabela, seguindo o padrão visual do Material Design. Ele 
permite estruturar dados em linhas e colunas por meio de DataColumn, DataRow e 
DataCell, sendo ideal para listas administrativas, catálogos, relatórios e registros 
estruturados. O DataTable suporta recursos como ordenação ao clicar no cabeçalho, 
células personalizadas (com texto, ícones ou botões) e rolagem horizontal/vertical 
quando combinado com SingleChildScrollView. Para grandes conjuntos de dados, 
pode ser usado junto ao PaginatedDataTable, que adiciona paginação automática. 
Por ser flexível, permite personalização de cores, espaçamento, alinhamento e estilo 
das células, tornando fácil exibir dados de forma profissional, clara e responsiva 
dentro do aplicativo.
